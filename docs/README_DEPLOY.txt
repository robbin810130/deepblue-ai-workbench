# 部署/测试说明 (Deployment Guide)

## 如何打包发送给其他人？

1.  **复制整个文件夹**：
    将 `d:\my-web-os` 文件夹完整复制一份（或者压缩成 zip 包）。
    
    *注意*：如果接收方电脑的网络环境较差，建议保留 `node_modules` 文件夹一起打包发送。如果对方熟悉技术，可以删除 `node_modules` 以减小体积，但对方需要运行 `npm install`。

2.  **发送给同事**：
    将压缩包发送给同事，让他解压到任意目录。

## 如何启动 (接收方操作)？

1.  **环境要求**：
    - 电脑上必须安装 [Node.js](https://nodejs.org/) (建议版本 v18 或以上)。
    - 如果需要生成预测数据，需要安装 Python。

2.  **启动方法**：
    - 双击运行根目录下的 `start_production.bat` 脚本。
    - 脚本会自动检测环境并启动服务。

3.  **访问地址**：
    - 启动成功后，浏览器会自动打开或手动访问：`http://localhost:8081`
    - 局域网其他电脑访问：`http://[他的IP地址]:8081` (如果他也需要被别人访问，他也需要运行 `setup_firewall.bat`)

## 常见问题

- **端口被占用**：如果启动失败提示端口被占用，请检查是否已经运行了其他服务（比如现在的开发服务器 `npm run dev`），请先关闭它们。
## 如何在该服务器上保持长期运行？ (推荐)

如果你希望服务器重启后项目也能自动启动，或者希望即使关闭了终端窗口项目也能在后台运行，请使用以下方法：

1.  **安装并启动服务**：
    - 右键以管理员身份运行 **`setup_pm2.bat`**。
    - 脚本会自动安装 PM2 进程管理器，并询问是否设置为开机自启（输入 Y 确认）。

2.  **常用管理命令**：
    在终端（cmd 或 PowerShell）中输入：
    - `npx pm2 status`        - 查看运行状态
    - `npx pm2 logs my-web-os` - 查看实时日志
    - `npx pm2 restart my-web-os` - 重启服务
    - `npx pm2 stop my-web-os`    - 停止服务
