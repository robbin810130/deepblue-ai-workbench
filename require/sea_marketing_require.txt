# 出海本地化营销内容生成（东南亚）模块需求文档

## 1. 模块概述
本模块旨在帮助出海东南亚市场的商家一键生成多语种、多平台的本地化电商营销内容。只需输入产品基础信息即可得到针对不同平台（TikTok, Shopee, Lazada）优化的文案。

## 2. 功能需求

### 2.1 输入组件
- **产品名称**：单行输入框，必填。
- **产品信息**：多行文本框，必填，用于输入产品的核心卖点、参数等。
- **成分/材质**：多行文本框，选填，输入产品成分或材质说明。
- **目标语种**：下拉选择器（选项：英语 / 印尼语 / 越南语 / 泰语），必填。
- **目标平台**：下拉选择器（选项：TikTok / Shopee / Lazada），必填。
- **营销风格**：下拉选择器（选项：种草风格 / 专业风格 / 平价风格），必填。

### 2.2 交互逻辑组件
- **生成按钮**：点击后打包所有表单输入参数，发送给 Dify 工作流，在结果成功返回前需处于 Loading 状态。
- **重置按钮**：一键清空以上所有输入框与下拉选择，并清空生成结果，重置到初始状态。

### 2.3 结果展示组件
界面需美观丰富，采用卡片或分区块的现代 UI 设计。整体布局上，左侧用户选择框高度需与右侧展示框高度一致，保持在一个页面中。

- **初始预览状态**：在运行前，前端结果展示框中需提供温馨提示，告知用户该智能体每次运行需要等待 2~3 分钟。
- **内容展示区域**：生成结果后，上方“生成完成”的提示需随结果滚动，避免对结果内容造成遮挡。展示以下三类生成内容：
- **SEO 优化标题**：
  - 展示卡片包含 5 条小语种标题。
  - 每条标题需配有独立的单条复制按钮。
- **电商详情页 Listing**：
  - 展示完整排版的商品详情文案。
  - 支持区域内滚动查看内容（防止过长挤占屏幕空间）。
- **KOC 社媒种草脚本**：
  - 展示编号版的短视频脚本。
  - 结构需清晰（例如明确分出 0-3s / 3-15s 等节奏点）。
- **平台商品卡片预览原型**：
  - 提供单选标题功能并配套平台模板下拉框（与目标平台联动：Shopee、Lazada、TikTok）。
  - 根据选中的标题和详情文案，实时组装生成高保真的平台样式前端组件卡片，用于演示。

## 3. UI/UX 视觉规范
- 整体风格贯彻现代、丰富、立体的设计审美。
- 各个结果展示板块建议使用不同风格的卡片包裹，配合装饰性图标。

## 4. API 接口对接
- 将复用或新建 `server.js` 上的 Dify 工作流调用代理服务，确保跨域与密钥安全。
