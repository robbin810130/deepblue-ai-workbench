# 营销分析模块需求文档

## 1. 模块概述
营销分析模块是面向业务部门的核心数据洞察平台，旨在展示 HLFGDERPzs260117 数据库中的月度及季度销量、销售额以及毛利等指标，并提供交互式可视化和 AI 智能分析对话功能。

## 2. 功能需求

### 2.1 销量与销售额数据源
- 取值自 HLFGDERPzs260117 SQL Server 数据库中的 `t_BillStockSale`、`t_BillStockSaleEntry`、`t_IcItem` 和 `t_Customer` 等表。
- 提取指标包括：
  - 月销量（月度销售数量 fQty 汇总）
  - 季销量（季度销售数量 fQty 汇总）
  - 月销售额（月度销售金额 fSaleAmount 汇总）
  - 季销售额（季度销售金额 fSaleAmount 汇总）
  - 毛利率（销售额与毛利占比）
  - 平均单价（fSaleAmount / fQty）
- 支持对销售数据按近一年总销量进行降序排列，筛选贡献前 80% 的 Top SKU。

### 2.2 核心指标与控制栏
- 汇总核心指标卡片（KPI Cards）：
  - 近一年总销量
  - 近一年总销售额
  - 综合平均单价
  - 综合加权平均毛利率
- 数据流控制：
  - 刷新/更新数据按钮：调用后端执行 Python 脚本，重新从 SQL Server 抽取并计算最新数据。
  - 数据源与时间显示：清晰展示上次数据同步时间。
  - 数据类型切换：支持一键切换展示“销量数据 (Qty)”和“销售额数据 (Amount)”。
  - SKU 范围筛选：支持“销量前 10 名”、“销量 11-20 名”、“销量 21-30 名”及“自定义选择”筛选。

### 2.3 交互式可视化趋势图表（SVG）
- 使用轻量、动态的 SVG 路径手写绘制多 SKU 销量/销售额对比折线图。
- 支持鼠标悬停 (Hover) 在特定月份/季度节点时展示浮动 Tooltip，包括该时间点的产品名称、销量、销售额及均价。
- 折线颜色使用高对比度、柔和美观的莫兰迪/渐变配色，并支持单条曲线高亮聚焦。
- 提供分类销量占比环形图 (Donut Chart)，直观显示“奶酪”、“果冻”等类别的贡献比例。

### 2.4 数据透视矩阵表格
- 月度 analysis 矩阵表与季度 analysis 矩阵表，支持纵向和横向滚动。
- 表头随时间维度动态生成，SKU ID 和产品名称固定在左侧 (Sticky)，防止滚动时错位。
- 在“自定义选择”模式下，表格首列提供 Checkbox 选项以支持多选 SKU 联动图表展示。

### 2.5 营销分析智能助手 (Dify Chatflow 闭环)
- 前端右侧提供宽幅营销数据智能 analysis 对话面板。
- 提供内置快捷指令 (Prompt Shortcuts)，如：“销量异常波动诊断”、“大单流失及原因分析”、“竞品毛利空间推演”。
- 聊天窗口支持历史消息渲染，气泡卡片展示，流式 (SSE) 文本输出。
- 使用 `react-markdown` 渲染排版，支持表格、列表及强调格式。
- 后端代理接口对接 Dify 营销数据分析工作流。

## 3. 布局与样式规范
- 页面分为左右两大板块：
  - 左侧 (65% 宽度)：仪表盘视图（KPI 卡片、SVG 趋势图、销量/销售额透视表）。
  - 右侧 (35% 宽度)：Dify AI 智能营销助手对话框。
- 风格采用深蓝/极光紫渐变与玻璃拟态 (Glassmorphism) 质感，背景细腻阴影，按钮支持 Hover 微交互与加载骨架屏。
- 桌面入口图标默认收纳于“核心业务”文件夹中，双击可展开运行，支持自由拖拽出入及右键菜单管理。

## 4. 优化与变更记录

### 4.1 修复产品名称列值显示错位 (2026-05-22)
- **原因分析**: 表格引擎在渲染具有较长文字的列时，会动态计算并调整 `td` 的宽度。当 `th` 和 `td` 仅使用常规 width 类且未严格限制 min-width / max-width 时，在横向滚动过程中，实际渲染列宽与 sticky 布局的 `left` 偏移量会产生偏差，导致错位和内容折叠覆盖。
- **解决方案**: 在表格头 `th` 和表格体 `td` 中对“多选框”列、`SKU 编号` 列和 `产品名称` 列统一增加像素宽度控制：
  - 多选框列: `w-[40px] min-w-[40px] max-w-[40px]` (左粘滞偏移: `left-0`)
  - SKU 编号列: `w-[112px] min-w-[112px] max-w-[112px]` (左粘滞偏移: `left-[40px]`)
  - 产品名称列: `w-[192px] min-w-[192px] max-w-[192px]` (左粘滞偏移: `left-[152px]`)
  同时开启 `truncate` 截断并指定 `title` 属性，修复了表格在水平滚动时的列值错位缺陷。

### 4.2 商品品牌名前端脱敏处理 (2026-05-22)
- **脱敏机制**: 引入并复用预测模块相同的 `useBrandMask` React Hook（定义于 `src/utils/demoMask.ts`）。
- **脱敏应用**:
  - **表格渲染**: 将表格中产品名称展示值和 `title` 属性包裹在 `maskProduct(sku.product_name)` 中，将匹配到的已知品牌名脱敏为 `**`。
  - **图表及交互组件**: 在计算图表 `chartConfig` 数据点（`linesData`）时，对 SKU 的 `productName` 字段在生成时调用 `maskProduct` 脱敏。这使得折线图底部的图例 (Legend) 以及鼠标 hover 弹出 Tooltip 中的产品名称自动脱敏，在前端界面全面实现了数据脱敏要求。

### 4.3 表格固定列背景颜色、字体样式及悬浮高亮优化 (2026-05-22)
- **原因分析**: 由于表格其余单元格采用透明/毛玻璃效果以透出底层系统背景，固定的左侧列（Checkbox、SKU编号、产品名称）和右侧列（合计）必须使用不透明的背景颜色，以防滚动时内容重叠穿透。原有固定的黑色背景色彩过深且无层次感，且之前 SKU 编号和产品名称字段的字体设计与右侧合计字段样式不统一，影响了整体美观度和数据可读性。
- **解决方案**:
  - **背景与悬浮样式对齐**：将 Checkbox、SKU 编号、产品名称和合计列的表头及行单元格的默认不透明背景调整为漂亮的暗钢蓝色 `#252f4a`，彻底摆脱死板的黑色。行悬停 (Hover) 时，背景颜色通过 `group-hover:bg-[#313d5e]` 连贯过渡到较亮的 `#313d5e`。选中状态切换为深靛蓝 `#2c336b`，并支持悬停高亮 `group-hover:bg-[#343d83]`。
  - **字体与颜色对齐**：将 **SKU 编号** 和 **产品名称** 的头部与单元格字体和文字颜色类全部改为与 **合计** 字段一致的 `font-bold` 以及 `text-indigo-300`，使整个表格的前端布局和视觉效果高度一致且极具质感。
### 4.4 产品名称列宽可手动调整 (2026-05-22)
- **功能描述**: 为了方便用户查看完整的长产品名称，将“产品名称”列由固定宽度（192px）改造为可自由调整宽度，大大提升数据查阅体验。
- **实现细节**:
  - 在“产品名称”表头右边缘嵌入绝对定位的微型拖拽手柄 (`cursor-col-resize`)。
  - 通过 React `useState` 动态保存 `prodNameWidth` 状态，并结合 `useRef` 和 `useCallback` 绑定全局 `mousemove` 和 `mouseup` 监听，保证拖拽流畅、无丢帧。
  - 设定了 `120px` 至 `500px` 的宽度保护阈值，防止极端调整导致表格布局崩塌，宽度变化时表头与数据行单元格完美同步自适应。
