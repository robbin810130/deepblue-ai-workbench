# 电商 AI 生图模块 (AIImageModule) 需求文档

## 1. 模块概述
该模块利用大模型技术，为电商用户提供产品生图、场景替换、智能检索等功能。支持多轮对话修改及参考图上传。

## 2. 核心功能
- **文字出图**：根据纯文字描述生成电商主图/详情页。
- **照片改图**：上传产品图，通过提示词改变背景或风格。
- **智能匹配**：分析上传的产品图，从数据库中检索相似产品。
- **模型选择**：**（新增）** 支持在生成前选择不同版本的大模型，如 Doubao seedream 系列。

## 3. 模型映射关系
| 界面显示名称 | 实际 API 模型 ID | 状态 |
| :--- | :--- | :--- |
| doubao-seedream-4.0 | doubao-seedream-4-0-250828 | 可用 |
| doubao-seedream-4.5 | doubao-seedream-4-5-251128 | 可用（默认） |
| Nano Banana | nano-banana | 暂不可用 |
| Gemini 3.1 Flash Image | gemini-3.1-flash | 暂不可用 |

## 4. 交互入口
- 顶部 Header 包含高级自定义模型选择组件。
- **视觉特性**：采用毛玻璃效果 (Backdrop-blur)、高级阴影及平滑过渡动画。
- 交互逻辑：点击触发器展开菜单，点击外部或选项自动关闭。
- 选择结果实时保存至模块状态，并在点击“生成”时通过 API 传递至后端。

## 5. 后端逻辑
- 接口 `/api/generate-image` 接收 `model` 参数。
- 默认模型设为 `doubao-seedream-4-5-251128`。
- 将模型 ID 转发至火山引擎 ARK API 完成图片生成。
