# 企业资质库模块 (Enterprise Qualification Library) 需求文档

## 1. 模块概述
企业资质库模块用于集中管理公司主体下的各类资质资产（含证照、账号、密钥、银行账户等），支持多主体隔离、敏感度分级、凭证加密存储、附件管理、到期预警与日历视图，并提供总览看板与审计追踪能力。

---

## 2. 数据库设计

共 5 张表。

### 2.1 字典表 (eq_dict)
一张表统一承载公司主体、一级分类、二级分类三类字典数据。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 主键 |
| dict_type | VARCHAR | 字典类型：entity / category_l1 / category_l2 |
| parent_id | INT FK→eq_dict.id | 上级字典（二级分类指向所属一级分类，主体和一级分类为空） |
| name | VARCHAR | 名称 |
| sort_order | INT | 排序号 |
| is_enabled | BOOLEAN | 启用状态 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

### 2.2 资产表 (eq_asset)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 主键 |
| asset_name | VARCHAR | 资产名称 |
| entity_id | INT FK→eq_dict.id | 所属主体 |
| category_l1_id | INT FK→eq_dict.id | 一级分类 |
| category_l2_id | INT FK→eq_dict.id | 二级分类 |
| asset_no_masked | VARCHAR(4) | 编号（只存脱敏后 4 位） |
| owner | VARCHAR | 负责人 |
| effective_date | DATE | 生效日期 |
| expiry_date | DATE | 到期日期 |
| status | VARCHAR | 状态（有效 / 待更新 / 已废弃 / 仅供参考） |
| sensitivity | INT | 敏感度等级 |
| visible_departments | TEXT[] | 可见部门数组（一个资产可被多个部门查看） |
| extra_fields | JSONB | 类型专属字段（按一级分类动态展示，如发证机构、登录账号、开户行等） |
| sync_to_dify | BOOLEAN | 是否推送 Dify 知识库（默认 false） |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

### 2.3 附件表 (eq_attachment)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 主键 |
| asset_id | INT FK→eq_asset.id | 所属资产 |
| file_path | VARCHAR | 文件路径 |
| folder_path | VARCHAR | 所在文件夹（保留上传时的目录结构） |
| original_name | VARCHAR | 原始文件名 |
| file_size | BIGINT | 文件大小（字节） |
| is_primary | BOOLEAN | 是否主附件 |
| sort_order | INT | 排序号 |
| checksum | VARCHAR | 文件校验值（去重用，SHA-256） |
| created_at | TIMESTAMPTZ | 上传时间 |

### 2.4 凭证表 (eq_credential)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 主键 |
| asset_id | INT FK→eq_asset.id | 所属资产 |
| cred_type | VARCHAR | 凭证类型：password / key / token / certificate |
| ciphertext | TEXT | 密文（AES-256-GCM 加密后的结果） |
| algorithm | VARCHAR | 加密算法（默认 AES-256-GCM） |
| recovery_method | VARCHAR | 找回方式 |
| rotation_days | INT | 轮换周期（天） |
| last_rotation | DATE | 上次轮换日期 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |

**不设任何明文字段。**

### 2.5 同步日志表 (eq_sync_log)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 主键 |
| asset_id | INT FK→eq_asset.id | 所属资产 |
| sync_action | VARCHAR | 同步动作：create / update / disable / delete |
| sync_status | VARCHAR | 同步状态：pending / success / failed |
| error_message | TEXT | 错误信息 |
| synced_at | TIMESTAMPTZ | 同步时间 |

仅记录 `sync_to_dify = true` 的资产的 PG → Dify 推送结果。

## 3. 后端接口设计

### 3.1 资产接口
- **资产增删改查**：CRUD 操作，查询时强制按权限过滤（可见主体 + 部门 + 敏感度）。
- **到期清单查询**：支持按天数范围筛选即将到期的资产列表。

### 3.2 附件接口
- **附件上传**：沿用 multer 磁盘存储，单文件 ≤ 10MB，白名单 pdf / jpg / png。支持多文件 + 整文件夹上传，保留文件夹名和目录结构。
- **附件删除**：按 ID 删除，同步清理磁盘文件。

### 3.3 凭证接口
- **凭证解密**：单独限流（每人每分钟最多 5 次），解密操作写入系统操作日志（sys_audit_logs）。

### 3.4 字典接口
- **字典增删改查**：一套通用接口，管主体和两级分类。删除前检查关联资产，有资产则阻止删除。

### 3.5 Dify 同步接口
- **手动触发同步**：对 `sync_to_dify = true` 的资产，支持单条或批量推送到 Dify 知识库。
- **同步状态查询**：读取 eq_sync_log 表，返回推送历史和最新状态。

## 4. 权限与多主体

### 4.1 权限维度
在现有权限表上扩展出三个维度：
- **可见主体**：用户所属公司主体。
- **部门**：用户所属职能部门。
- **敏感度**：用户敏感度等级。

### 4.2 资产可见性规则
同时满足以下三个条件时用户可查看资产：
1. 用户部门 ∈ 资产的可见部门数组。
2. 用户主体 ∈ 资产主体。
3. 用户敏感度等级 ≥ 资产敏感度。

### 4.3 过滤策略
- 前端登录后拿到权限，传给后端。
- 后端在查询时强制过滤（安全边界）。
- 前端过滤只做体验优化。

### 4.4 凭证限流
- 复用 3.3 凭证接口的限流规则，解密操作统一写入系统操作日志（sys_audit_logs）。

## 5. 功能页面

### 5.1 基础配置（主体/分类管理）

页面包含三个标签页：公司主体、一级分类、二级分类。

#### 5.1.1 公司主体标签
- 可添加、删除主体。
- 删除前检查该主体下有无资产，有则阻止删除并提示。

#### 5.1.2 一级分类标签
- 可添加、删除一级分类。
- 删除前检查有无关联资产，有则阻止删除并提示。

#### 5.1.3 二级分类标签
- 先选所属一级分类，再管理其下的二级分类。
- 支持添加、删除二级分类。

#### 5.1.4 联动刷新
- 分类/主体增删后，同步刷新台账筛选和新增资产弹窗的下拉选项。

#### 5.1.5 审计
- 所有增删操作写入系统操作日志（sys_audit_logs）。

---

### 5.2 资产台账（核心页面）

#### 5.2.1 资产列表
- 表格展示：资产名、主体、分类、负责人、到期日、状态、敏感度、Dify 推送标记。
- 编号只显示后 4 位（如 `****7C2D`），完整编号不入库、不展示。

#### 5.2.2 顶部筛选
- 公司主体切换器。
- 一级分类下拉。
- 二级分类下拉（与一级分类联动）。
- 状态筛选。
- 搜索框。

#### 5.2.3 新增资产弹窗
分为以下字段区域：

**基础字段**：
- 名称、编号、公司主体、职能部门（多选）、状态、敏感度、负责人、生效/到期日、是否推送 Dify 知识库。

**分类字段**：
- 选一级分类后，二级分类下拉自动联动。

**类型专属字段**：
- 按一级分类动态展示不同字段：
  - 资质类 → 显示发证机构。
  - 账号类 → 显示登录账号/密码。
  - 银行账户类 → 显示开户行/账号等。

**凭证字段**：
- 密码/密钥/银行完整账号，输入后加密存储，界面不回显。

**附件**：
- 支持多文件 + 整文件夹上传，保留文件夹名和目录结构。

#### 5.2.4 资产详情抽屉
- 展示全部字段（含推送标记状态）。
- 附件列表（含文件夹树结构展示）。
- 凭证解密按钮（调用解密接口，权限校验 + 限流）。
- Dify 同步状态与推送历史（读取 eq_sync_log）。
- 编辑按钮。
- 创建续期事项按钮。

### 5.3 总览看板

#### 5.3.1 顶部指标卡（4 个）
- 资产总数。
- 待更新数。
- 30 天内到期数。
- 高敏感凭证数。

#### 5.3.2 状态分布环形图
- 按状态分组：有效 / 待更新 / 已废弃 / 仅供参考。

#### 5.3.3 各公司主体资产分布柱状图

#### 5.3.4 未来 6 个月到期趋势图

#### 5.3.5 临期资产清单
- 展示 60 天内到期的资产列表。
- 点击可跳转到资产详情。

---

### 5.4 到期日历

#### 5.4.1 月历视图
- 有资产到期的日期做标记。

#### 5.4.2 到期高亮分档
- 提前 90 天：绿色。
- 提前 60 天：黄色。
- 提前 30 天：红色。

#### 5.4.3 日期详情
- 点击某天显示当天到期的资产清单。

---

### 5.5 凭证管理

#### 5.5.1 列表范围
- 只列账号类资产：业务平台入驻账号、API 密钥、银行账户。

#### 5.5.2 列表字段
- 账号标识（脱敏显示）。
- 凭证类型。
- 加密存储说明。
- 轮换周期。
- 下次轮换日。

#### 5.5.3 解密查看
- 点击「解密查看」按钮，调用解密接口。
- 权限校验 + 限流通过后展示明文。
- 8 秒后自动隐藏明文。
- 全程写入系统操作日志（sys_audit_logs）。
