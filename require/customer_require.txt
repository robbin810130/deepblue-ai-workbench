# 客户分析模块需求文档 (customer_require.txt)

## 1. 模块概述
客户分析模块基于 `a3_customer_analysis.py` 输出的 JSON 数据，通过 RFM 模型、需求稳定性 CV 及流失风险预警三个核心维度对客户进行立体画像，最终生成：
- 客户分层清单
- 定制化订货建议（AI，待接入）
- 异动预警提醒

## 2. 数据来源
| 数据源 | 类型 | 路径 |
|---|---|---|
| Python 脚本 | 实时计算 | `a3_customer_analysis.py` |
| 前端 JSON | 静态读取 | `public/customer_analysis.json` |

JSON 字段含义（14 列）：
- 客户ID、客户名称、客户所属区域
- R_最近提货天数（=分析日 - 最后提货日，正值=近期未提货天数）
- F_提货频次
- M_总提货金额
- R/F/M_评分（1~5分制，越高越好）
- RFM总分（三项之和）
- 客户分层：核心客户(≥12)、重要客户(≥9)、普通客户(≥6)、低价值客户(<6)
- 订单变异系数CV（需10笔以上近年订单才计算，否则null）
- 需求稳定性：非常稳定(CV<0.5)、稳定(CV<1.0)、一般(CV<1.5)、不稳定
- 流失风险等级：高危流失(R>=180天)、预警流失(R>=90天)、低风险

## 3. 前端功能

### 3.1 概览卡片区
- 参与分析客户总数（蓝色横幅）
- 四种客户分层数量卡片 + 占比进度条
- 三种流失风险数量分布

### 3.2 Tab 1: 客户分层清单
- 关键词搜索（ID/名称/区域）
- 下拉筛选（客户分层 & 流失风险）
- 可排序数据表格（10列，点击表头排序）
- "更新数据"按钮 → 触发 POST /api/update-customer-analysis

### 3.3 Tab 2: 定制化订货建议
- 当前为占位状态，待 Dify Chatflow 接入后开发

### 3.4 Tab 3: 异动预警提醒
- 顶部统计横幅（高危/预警数量 + 渐变色卡片）
- 客户卡片列表：名称、ID、区域、最近提货时间、提货频次、总提货额、分层、RFM分
- 筛选按钮（全部异动 / 高危流失 / 预警流失）+ 搜索框

## 4. 后端 API

| 路由 | 方法 | 说明 |
|---|---|---|
| `/api/update-customer-analysis` | POST | 运行 Python 脚本，将 JSON 写入 `public/customer_analysis.json` |
| `/api/customer-analysis` | GET | 读取并返回 `public/customer_analysis.json` |
