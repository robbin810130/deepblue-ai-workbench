# 数据库设计文档

**项目名称：** 智能体集成平台 (Agent Integration Platform)
**数据库类型：** PostgreSQL

> [!NOTE]
> **新老划断原则**：
> 本设计规范从即日起生效，**仅适用于新增加的业务模块和表**。现有的数据库表（如 `ref_ai_scenes`、`sys_users` 等）及关联的老代码查询保持原样，不做重构，以保障现有业务稳定性。

**命名规范参考：**
1. **表命名**：`t_项目简称_表名`（大驼峰，例：`t_Cms_User`）
2. **字段命名**：`f字段名`（小驼峰，例：`fUserId`）
3. **字段约束**：整数 `integer`，小数 `decimal`，字符串 `varchar`，日期 `date`，时间 `timestamp`。除日期/时间外，禁止为 null，须有默认值。
4. **主键命名**：`f表名Id`（小驼峰）
