# 预测功能使用与维护手册

## 1. 功能概述

本项目实现了由于SKU数量较多导致大模型输入Token限制问题的解决方案：**分批次全量预测**。
系统会自动将91个SKU分为7个批次（每批15个），通过Dify API进行流式预测，并具备自动重试和实时保存功能。

## 2. 核心脚本

### generate-monthly-forecast.js
- **功能**：生成月度预测基线
- **位置**：项目根目录
- **执行方式**：
  ```bash
  node generate-monthly-forecast.js
  ```
- **配置项**（脚本顶部）：
  - `BATCH_SIZE = 15`: 每批SKU数量
  - `BATCH_DELAY = 3000`: 批次间等待时间（毫秒）
  - `MAX_RETRIES = 3`: API失败重试次数

## 3. 定时任务

系统已配置Node-cron定时任务：
1. **每月1号 02:00**: 自动执行全量预测
2. **每月5,10,15,20,25号 08:00**: 执行销售偏差跟踪

## 4. 故障排查

### 常见问题：API返回400
- **原因**：API URL配置错误或应用类型不匹配
- **解决**：检查`.env`文件，确保使用`/v1/chat-messages`端点（对应"聊天助手"类型应用）

### 常见问题：预测中断
- **原因**：网络波动或API超时
- **解决**：脚本已内置重试机制。如果完全失败，重新运行脚本即可（脚本会覆盖旧文件）。目前脚本支持实时保存，但重新运行建议为全量模式以确保数据一致性。

### 常见问题：前端显示空白
- **原因**：`monthly_forecast_baseline.json`文件缺失或格式错误
- **解决**：运行生成脚本重新生成数据文件。

## 5. 数据文件

- `public/monthly_forecast_baseline.json`: 存储月度预测结果
- `public/forecast_tracking.json`: 存储偏差跟踪结果
