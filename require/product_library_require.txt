# 选品库模块需求文档 (ProductLibraryModule)

## 1. 功能描述

选品库模块提供商品数据的多维筛选与列表浏览能力。用户通过左侧筛选面板设置过滤条件，点击查询按钮后右侧展示符合条件的商品列表。数据通过 Dify 工作流获取。

### 1.1 核心能力

- **多维筛选**：支持按品牌、供应商、分类、条码、建议零售价等多个维度进行组合过滤，均为文本输入框。
- **预置条件**：无需预置数据，所有筛选项均为用户手动输入文本进行模糊匹配。
- **商品列表展示**：以表格形式展示筛选后的商品数据。
- **按钮查询**：筛选条件变更后，用户需点击"查询"按钮才会触发数据刷新。

## 2. 核心流程

### 2.1 筛选查询流程

1. 用户进入模块，右侧展示空列表。
2. 用户在左侧筛选面板中输入文字进行过滤：
   - 品牌：文本输入框，模糊匹配。
   - 供应商：文本输入框，模糊匹配。
   - 分类：文本输入框，模糊匹配。
   - 条码：文本输入框，模糊匹配。
   - 建议零售价区间：两个数字输入框（最低 ~ 最高）。
3. 用户点击"查询"按钮，前端携带当前筛选参数请求后端接口，右侧商品列表刷新展示查询结果。
4. 用户可点击"重置"按钮清空所有筛选条件。

## 3. 视觉优化需求

### 3.1 整体布局

- **左右分栏**：左侧为筛选面板（固定宽度约 280px），右侧为商品列表区域（自适应剩余宽度）。
- **响应式**：小屏场景下左侧筛选面板可折叠收起。
- **风格统一**：与 WebOS Pro 整体深色/科技风格保持一致，使用 Tailwind CSS 定制。

### 3.2 左侧筛选面板

- **面板标题**：顶部显示"筛选条件"标题，右侧放置"重置"按钮。
- **筛选项排列**：各筛选项垂直排列，每项包含标签和输入控件，间距均匀。
- **筛选项**：
  - 品牌、供应商、分类、条码：均为文本输入框，placeholder 为"输入xxx搜索"。
  - 建议零售价区间：两个数字输入框（最低 ~ 最高）。
- **筛选按钮**：面板底部固定"查询"按钮（主色调）和"重置"按钮（灰色描边）。

### 3.3 右侧商品列表

- **表格样式**：表头固定，背景深色，文字白色；数据行交替底色（斑马纹），hover 行高亮。
- **表格列定义**：

| 列名 | 说明 | 对齐 |
|------|------|------|
| 商品名称 | 商品中文名称 | 左对齐 |
| 品牌 | 所属品牌 | 左对齐 |
| 供应商 | 供应商名称 | 左对齐 |
| 分类 | 商品分类 | 左对齐 |
| 条码 | 商品条码 | 居中 |
| 规格 | 商品规格 | 左对齐 |
| 产地 | 生产产地 | 左对齐 |
| 建议零售价 | 格式化为货币（¥XX.XX） | 右对齐 |
| 毛利率 | 格式化为百分比 | 右对齐 |
| 状态 | 上架/下架标签 | 居中 |

- **空状态**：无数据时展示空状态插图 + 提示文字。
- **加载态**：查询中展示骨架屏或加载动画。

### 3.4 美观性

- 筛选面板与列表之间有明确的视觉分隔。
- 筛选面板背景略深于列表区域，形成层次感。
- 查询按钮 hover 有轻微上浮效果。
- 商品列表行 hover 时有视觉反馈。

## 4. 技术实现

### 4.1 前端

- **组件文件**：`src/components/ProductLibraryModule.tsx`
- **布局方案**：Flexbox 左右分栏，左侧 `w-[280px]` + 右侧 `flex-1`。
- **状态管理**：`useState` 管理筛选条件对象。
- **分类联动**：无需分类联动，分类为单一文本输入框。
- **数据请求**：使用 `authFetch` 封装请求函数，携带筛选参数和分页信息调用后端 API。

### 4.2 后端

- **路由前缀**：`/api/product-library`
- **接口设计**：

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/product-library/products` | 查询商品列表（调用 Dify 工作流） |

- **请求参数**（`POST /api/product-library/products`，JSON Body）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| brand | string | 否 | 品牌（模糊匹配） |
| supplier | string | 否 | 供应商（模糊匹配） |
| category | string | 否 | 分类（模糊匹配） |
| barcode | string | 否 | 条码（模糊匹配） |
| price_min | number | 否 | 建议零售价下限 |
| price_max | number | 否 | 建议零售价上限 |

- **Dify 工作流调用**：
  - 后端将筛选参数组装为 `inputs`，调用 Dify `/v1/workflows/run` 接口。
  - 工作流返回商品列表数据（JSON 格式），后端解析后转发给前端。

### 4.3 环境变量

```env
# 选品库 - Dify 工作流配置
DIFY_PRODUCT_LIBRARY_API_KEY=your_api_key_here
DIFY_PRODUCT_LIBRARY_API_URL=https://api.dify.ai/v1
```

### 4.4 前端配置变更

- **`src/config.ts`**：新增 API 端点常量 `PRODUCT_LIBRARY_API`。
- **`src/types/index.ts`**：`ModuleType` 联合类型新增 `'productLibrary'`。
- **`src/config/permissionConfig.ts`**：`APP_META` 中注册模块元信息（label: "选品库"）。
- **`src/components/SystemInterface.tsx`**：添加 `React.lazy()` 动态导入和渲染逻辑。
