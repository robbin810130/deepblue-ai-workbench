# 版式对比模块需求文档 (LayoutCompareModule)

## 1. 功能描述
版式对比模块是一个 AI 驱动的视觉分析工具，用于对比基准版式（A）与修改版式（B）之间的视觉落差和细节差异。系统支持单图识别（左右分栏）和多图对比。

## 2. 核心流程
1. 用户上传基准版式图（必填）。
2. 用户上传对比版式图（选填，若为空则假设基准图包含多版式）。
3. 调用 Dify 工作流进行 AI 分析。
4. 渲染分析结果。

## 3. 视觉优化需求 (2026-03-14 更新)
- **结果换行**：分析结果应按照类别或条目进行换行显示，避免长文本堆叠。
- **差异高亮**：使用清晰的视觉提示（如颜色、加粗、箭头图标）展示“从 A 到 B”的变化过程。
- **排版结构**：采用列表或表格形式呈现，增强可读性。
- **美观性**：结果框应具有现代感，背景、内边距和动画效果应与整体 UI 保持一致。

## 4. 技术实现
- 使用 `ReactMarkdown` 配合 `remarkGfm` 和 `rehypeRaw`。
- 前端对后端返回的原始文本进行结构化预处理。
- 利用 Tailwind CSS 进行样式定制。
