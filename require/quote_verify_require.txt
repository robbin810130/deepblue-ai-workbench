# 核查报价模块需求文档 (QuoteVerifyModule)

## 1. 功能描述
核查报价模块用于对供应商报价进行 AI 核查。页面采用左右布局：左侧为操作区，包含供应商名称输入框和文件上传框；右侧为结果展示区，展示核查报价结果列表。

## 2. 核心流程

### 流程一：供应商名称核查
1. 用户在左侧供应商输入框中填写供应商名称。
2. 点击查询按钮，调用 Dify 工作流接口（工作流A），将供应商名称作为参数传入。
3. 工作流A 返回核查报价结果列表。
4. 右侧结果区以列表形式展示核查报价结果。

### 流程二：文件上传核查
1. 用户在左侧文件上传框中上传报价文件。
2. 点击上传按钮，调用 Dify 工作流接口（工作流B），将文件传输至 Dify 进行处理。
3. 工作流B 返回处理结果（成功/失败信息）。
4. 右侧结果区展示成功或失败信息。

## 3. 视觉优化需求
- **左右布局**：左侧为操作区（供应商输入框 + 文件上传框），右侧为结果展示区。
- **排版结构**：核查报价结果采用列表或表格形式呈现，增强可读性。
- **美观性**：结果框应具有现代感，背景、内边距和动画效果应与整体 UI 保持一致。

## 4. 技术实现
- 前端组件：`src/components/QuoteVerifyModule.tsx`
- 使用 `ReactMarkdown` 配合 `remarkGfm` 和 `rehypeRaw` 渲染结果文本。
- 前端对后端返回的原始文本进行结构化预处理。
- 利用 Tailwind CSS 进行样式定制。

## 5. 后端接口
- `POST /api/quote-verify/run` — 传入供应商名称，调用 Dify 工作流A，返回核查报价结果列表
- `POST /api/quote-verify/upload` — 上传报价文件，调用 Dify 工作流B，返回成功/失败信息
- 环境变量：
  - 工作流A（供应商名称核查）：`DIFY_QUOTE_VERIFY_API_KEY` / `DIFY_QUOTE_VERIFY_API_URL`
  - 工作流B（文件上传核查）：`DIFY_QUOTE_VERIFY_FILE_API_KEY` / `DIFY_QUOTE_VERIFY_FILE_API_URL`
