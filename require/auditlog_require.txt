# 系统操作日志模块 (auditlog) 需求文档

## 1. 模块概述
系统操作日志模块旨在提供全方位的操作审计与业务行为追踪，记录“谁、何时、在哪个模块、做了什么、结果如何”，以及详细的业务负载（Payload）。

## 2. 核心功能
### 2.1 自动录入
- **鉴权审计**：记录登录成功、登录失败、退出登录等行为。
- **管理操作**：记录用户增删改、角色权限变更、密码重置等敏感操作。
- **AI 智能体追踪**：记录所有 AI 模块（市场洞察、营销预测、合规审核等）的调用，包含用户输入的 Query 及上传的文件名。
- **个人中心**：记录用户更新头像、修改基本信息、改密等行为。

### 2.2 日志查看器
- **列表展示**：支持分页加载，展示 ID、账号、模块、行为、目标数据、时间。
- **组合筛选**：支持按账号名、所属模块（下拉选择）、执行动作（关键字）进行多维度过滤。
- **详情弹窗**：点击查看单条日志的完整信息，包括 1:1 还原的 JSON 业务参数、User Agent、请求 IP 等。

## 3. 技术实现
- **数据库**：PostgreSQL `sys_audit_logs` 表。
- **后端工具**：`logAudit(req, data)` 全局 hook。
- **前端组件**：`AuditLogModule.tsx`，使用 Lucide React 图标与 Tailwind CSS 深度美化。

## 4. 安全与维护
- **权限控制**：仅 `admin` 角色可访问该模块。
- **只读属性**：日志界面仅提供查询与查看，不提供任何修改或删除功能（保障审计公正性）。
- **性能优化**：采用异步写入模式，不阻塞主业务流程。
