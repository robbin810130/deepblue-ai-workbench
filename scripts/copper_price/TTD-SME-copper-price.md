# TTD：SME 信息网当日铜平均价获取脚本

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0 |
| 状态 | 已确认，待实现 |
| 目标平台 | Windows / Python 3.14.2 |
| 数据源 | SME 信息网（`https://info.smechina.com.cn/`） |
| 目标数据 | 铜的当日平均价，单位：元/吨 |

## 2. 背景与目标

调用方需要一个可被其他程序调用的 Python 命令行工具，用于按需读取 SME 信息网首页公开展示的铜报价，并返回一个 JSON 对象。页面报价行的列语义为：产品、最低价、最高价、平均价、涨跌、更新时间；目标字段为“铜”行的“平均价”。

示例页面内容中，“铜”一行的最低价、最高价、平均价分别为 `109430`、`109550`、`109490`；本脚本返回 `109490`，不自行计算均值。

## 3. 范围

### 3.1 包含

- 从公开首页按需读取 HTML；不需要登录、账号、Cookie 或浏览器自动化。
- 解析“铜”行的平均价。
- 向标准输出返回成功 JSON。
- 在获取或解析失败时向标准错误返回错误 JSON，并以非零状态码结束。
- 通过离线 HTML 样本测试解析逻辑。

### 3.2 不包含

- 定时调度、数据库保存、历史行情、批量采集或价格计算。
- SMM/上海有色网的访问、任何需要认证的数据源、Cookie 管理或验证码处理。
- 浏览器驱动（Playwright/Selenium）及页面交互。
- 向网站提交数据、绕过访问控制或高频请求。

## 4. 方案与架构

采用单进程命令行脚本，依赖 `requests` 和 `beautifulsoup4`：

```text
外部调用方
    │ 启动 Python 脚本
    ▼
HTTP 客户端 ──GET──> SME 首页
    │ HTML
    ▼
报价解析器 ──> 数据校验与标准化 ──> stdout JSON
                                  └─> 失败：stderr JSON + 非零退出码
```

浏览器自动化不纳入方案：当前页面为服务端返回的 HTML，脚本只需低频 GET 请求即可。解析器以产品文本与相对字段关系定位，避免使用用户提供的绝对 XPath（其会随页面布局轻微调整而失效）。

## 5. 接口设计

### 5.1 命令

```powershell
python sme_copper_price.py
```

脚本不接受账号、密码、Cookie 或命令行密钥。调用方负责调度和重试策略之外的业务处理。

### 5.2 成功响应

退出码为 `0`，标准输出为一行 UTF-8 JSON：

```json
{
  "price": 109490,
  "unit": "元/吨",
  "product": "铜",
  "price_date": "2026-08-26",
  "source": "SME信息网",
  "fetched_at": "2026-08-26T12:00:00+08:00"
}
```

字段规则：

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `price` | integer | 目标行“平均价”，去除空白和千分位分隔符后转换；必须大于 0。 |
| `unit` | string | 固定为 `元/吨`。 |
| `product` | string | 固定为 `铜`。 |
| `price_date` | string | 优先解析页面可识别的完整报价日期；如页面只显示更新时间，则取抓取时刻的 `Asia/Shanghai` 日期。 |
| `source` | string | 固定为 `SME信息网`。 |
| `fetched_at` | string | 实际成功取得并解析页面时刻，ISO 8601，时区 `+08:00`。 |

### 5.3 失败响应

退出码为 `2`，标准错误输出一行 UTF-8 JSON；标准输出不输出业务数据：

```json
{
  "error": {
    "code": "SOURCE_CHANGED",
    "message": "未找到铜报价行或平均价字段"
  }
}
```

错误码：

| 错误码 | 触发条件 |
| --- | --- |
| `NETWORK_ERROR` | DNS、连接或读取超时。 |
| `HTTP_ERROR` | HTTP 状态码不是 2xx。 |
| `SOURCE_CHANGED` | 找不到“铜”行、字段数量不足或平均价格式无效。 |
| `UNEXPECTED_ERROR` | 未预期异常；消息不得暴露响应内容或本地敏感信息。 |

## 6. 获取与解析设计

### 6.1 HTTP 请求

- 请求方法：`GET`。
- 地址：`https://info.smechina.com.cn/`。
- 超时：连接 5 秒、读取 15 秒。
- 请求头：仅设置正常且固定的 `User-Agent` 与 `Accept: text/html`；不伪造 Cookie、Referer 或浏览器指纹。
- 重试：仅在连接异常、超时和 HTTP 5xx 时重试 1 次；两次请求间等待约 0.5 秒。4xx 与解析失败不重试。
- 频率：由外部调用方控制，建议不高于每 5 分钟 1 次；脚本不循环请求。

### 6.2 DOM 定位算法

1. 以响应声明的编码解码 HTML，并由 BeautifulSoup 建立 DOM。
2. 在报价区域 `ul#n_1` 内遍历 `li`；查找文本（优先 `a[title="铜"]`，回退为规范化可见文本）精确等于 `铜` 的行。
3. 在该行中按 DOM 顺序读取 `span.s2`。截图所示结构中其顺序为最低价、最高价、平均价，因此取第 3 个（索引 2）。
4. 将值中的空白、逗号等格式字符移除后解析为整数，并校验值大于 0。
5. 可选读取该行更新时间与页面完整日期；不将仅有的时间（如 `10:30`）误当作报价日期。
6. 构造成功 JSON。

若 `ul#n_1` 或主结构变更，解析必须失败并返回 `SOURCE_CHANGED`，不得猜测其他行或将最低价/最高价误作平均价。

## 7. 模块边界

| 模块 | 职责 | 输入/输出 |
| --- | --- | --- |
| `fetch_html()` | 请求首页、超时与有限重试 | URL → HTML 字符串；抛出受控获取异常。 |
| `parse_copper_price()` | 定位铜行、提取并校验平均价 | HTML → 价格及可用的页面日期信息。 |
| `build_response()` | 注入元数据并序列化成功结果 | 解析结果 → JSON 对象。 |
| `main()` | 编排、输出和退出码映射 | 无 → stdout/stderr 与退出码。 |

解析器不得依赖网络，保持为纯函数，以便离线测试。

## 8. 可靠性、安全与合规

- 全程 HTTPS；`requests` 保持证书校验开启。
- 不处理或保存账号、密码、Cookie、Token、代理地址或响应中的敏感内容。
- 日志只记录错误类别、HTTP 状态（如有）和请求耗时；不记录页面全文。
- 使用公开页面仍应遵循站点的使用规则与合理访问频率。若页面改为登录、付费或禁止自动访问，停止调用并改用得到授权的数据接口。
- 价格为第三方发布信息。调用方应保留 `source`、`price_date` 和 `fetched_at`，不得把抓取时间误解为报价发布时刻。

## 9. 测试与验收

### 9.1 单元测试

使用保存的、脱敏的 HTML fixture，不访问真实站点：

1. 铜行最低/最高/平均价为 `109430`/`109550`/`109490` 时，返回整数 `109490`。
2. 铜行不存在时返回 `SOURCE_CHANGED`。
3. 铜行 `span.s2` 少于 3 个时返回 `SOURCE_CHANGED`。
4. 平均价为 `--`、空值、负数或非数字时返回 `SOURCE_CHANGED`。
5. 同页存在其他金属时，仅选择产品精确为“铜”的行。
6. 含逗号和空白的合法数值可正确标准化。

### 9.2 集成测试

使用 HTTP mock 覆盖：成功 200、超时、500 后重试成功、404 不重试，以及网络异常。断言成功使用 stdout/退出码 0，失败使用 stderr/退出码 2。

### 9.3 验收条件

- 在 Windows + Python 3.14.2 中可运行。
- 对符合当前页面结构的 fixture，输出满足第 5.2 节的 JSON，`price` 等于平均价。
- 出现异常页面或网络问题时，不输出错误价格，且调用方可从 JSON 错误码与退出码识别失败。
- 不出现任何认证配置、Cookie 读取、浏览器依赖或真实站点测试依赖。

## 11. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 页面 DOM 或列顺序变化 | 取价失败或取错字段 | 精确产品匹配、固定读取平均价位、严格校验、失败即停止。 |
| 网站短暂不可用 | 无最新价格 | 有限重试并返回可机器处理的 `NETWORK_ERROR`/`HTTP_ERROR`。 |
| 非交易时段数据未更新 | 返回上一报价日价格 | 保留 `price_date` 与 `fetched_at`，由调用方据日期决定是否采用。 |
| 访问规则调整 | 自动访问不再适用 | 低频访问；发现登录/禁止限制后停止并改用授权接口。 |
